# Serafim Transmissoes v2

Interface azul escuro #1a2f4d com logo Serafim, sem camera.
Botoes: Transmitir, Assistir, Mudo, Cheia, Compartilhar. TAXA 768p e LIVE ao vivo tela.

## Como atualizar no GitHub
1. Extraia este zip
2. No GitHub, repo Tela-, Upload files e suba todos os arquivos (public/index.html, public/logo.png, server.js, package.json, render.yaml) por cima dos antigos
3. Commit changes
4. O Render faz deploy sozinho

## Variaveis no Render (Environment)
TURN_URL, TURN_USERNAME, TURN_CREDENTIAL - ja configuradas com Metered

## Local
npm install
npm start
http://localhost:3000
